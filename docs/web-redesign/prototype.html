Description

## What this leg delivers

A design system and a UX specification for the read-only web view, plus a
static review prototype. **No production code changes.**

The status language must work without colour:

- six shapes, six glyphs, six words
- claimed is an overlay, not a status
- *blocked* and *reviewable* are derived flags

Read the full document for the measured contrast pairs. See the
[WCAG 2.2 quick reference](https://www.w3.org/WAI/WCAG22/quickref/) and the
[MDN custom properties guide](https://developer.mozilla.org/en-US/docs/Web/CSS/Using_CSS_custom_properties).

```text
A -> B   means B depends on A
```

That is the only direction rule in the whole view.
